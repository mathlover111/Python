## 📁 Step 02：基礎語法
變數宣告、使用者輸入（`input`）、型態轉換，以及基礎數學運算

* **`02_f-string.py`**
  * **功能**：輸入名字，並輸出個人化的問候語
  * **重點**：學習 `input()` 取得使用者資料，並透過 `f-string` 格式化輸出

* **`03_currency_converter.py`**
  * **功能**：輸入台幣金額，依匯率 32 換算成美金
  * **重點**：學習 `float()` 型態轉換，避免文字與數字相除報錯

* **`04_square.py`**
  * **功能**：輸入邊長，自動算出正方形的周長與面積（只印出數字）
  * **重點**：將同一個輸入數值同時進行乘法與平方運算

* **`05_temp_converter.py`**
  * **功能**：將攝氏溫度轉換為華氏溫度
  * **重點**：實作數學公式計算：`celsius * 1.8 + 32`

* **`06_string_multiplier.py`**
  * **功能**：輸入任意單字與次數，將單字重複印出
  * **重點**：學習 `int()` 轉換，並利用 Python 特有的「字串 * 數字」特性

## 📁 Step 03：流程控制
本階段進入邏輯核心，練習條件判斷式（`if`、`elif`、`else`）、邏輯運算子（`and`、`or`、`!=`），以及 `for` 與 `while` 迴圈

* **`01_odd_even.py`**
  * **功能**：輸入一個整數，判斷是奇數還是偶數
  * **重點**：使用 `% 2` 取餘數，並認識 `==` 比較運算子

* **`02_score_level.py`**
  * **功能**：輸入分數，自動判斷並顯示 A、B、C 或不及格
  * **重點**：學習多重條件判斷 `elif` 的由上到下執行順序

* **`03_ticket_price.py`**
  * **功能**：判斷是否符合「免票」或「全票 200 元」資格
  * **重點**：學習邏輯運算子 `or`（多條件中只要一者滿足即可）

* **`04_leap_year.py`**
  * **功能**：輸入年份，自動計算並判斷是閏年還是平年
  * **重點**：綜合運用 `and`、`or` 以及 `!=`（不等於）處理複雜邏輯

* **`05_print_numbers.py`**
  * **功能**：自動印出 1 到 10 的數字
  * **重點**：掌握 `for` 迴圈與 `range()` 區間包頭不包尾

* **`06_sum_1_to_100.py`**
  * **功能**：自動算出 1 加到 100 的總和。
  * **重點**：建立累加變數，並練習 `total += i` 簡寫

* **`07_nine_nine.py`**
  * **功能**：自動印出完整的 1x1 到 9x9 乘法表
  * **重點**：實作雙重迴圈（Nested Loop），理解外圈與內圈的連動邏輯

* **`08_guess_number.py`**
  * **功能**：讓使用者一直猜數字，猜對才結束程式。
  * **重點**：學習 `while` 迴圈，用於不確定重複次數。

* **`09_break_continue.py`**
  * **功能**：印出 1 到 10，但跳過 4、並在遇到 8 時提早結束。
  * **重點**：掌握 `continue`（跳過本輪）與 `break`（中斷迴圈）指令。

* **`10_password_check.py`**
  * **功能**：模擬 ATM 輸入密碼，最多錯 3 次即鎖定。
  * **重點**：綜合運用迴圈次數限制、密碼判斷與 `break` 提早結束。

## 📁 Step 04：資料結構
本階段深入學習 Python 的三大核心資料結構：列表（List）、元組（Tuple）與字典（Dict），練習如何有效率地儲存與處理多筆資料。

* **`01_fruit_list.py`**
  * **功能**：建立水果列表、印出指定位置的水果，並在尾端加入新水果。
  * **重點**：掌握列表 `[ ]` 語法、索引值（Index）從 0 開始計算，以及 `append()` 的用法。

* **`02_score_average.py`**
  * **功能**：儲存多位學生成績，並自動計算出總分、人數與平均分數。
  * **重點**：學習使用內建函式 `sum()` 計算總和、`len()` 計算列表長度。

* **`03_max_min.py`**
  * **功能**：從成績列表中自動找出最高分與最低分。
  * **重點**：掌握內建函式 `max()` 與 `min()` 快速抓取極值的技巧。

* **`04_list_slice.py`**
  * **功能**：從已排序的成績清單中，直接切片抓出前三名的成績。
  * **重點**：學習 `[開始:結束]` 的列表切片（Slicing）機制，同樣遵守「包頭不包尾」原則。

* **`05_loop_list.py`**
  * **功能**：使用迴圈逐一取出名字清單，並印出個人化的問候語。
  * **重點**：掌握 `for name in names:` 遍歷列表的簡潔語法。

* **`06_tuple_basics.py`**
  * **功能**：建立儲存螢幕解析度的唯讀設定值，並讀取寬度。
  * **重點**：認識元組 `( )` 的不可變（Immutable）特性，適用於保護不希望被修改的資料。
  
* **`07_dict_basics.py`**
  * **功能**：建立包含名字與電話的個人聯絡資料字典，並讀取特定的電話號碼。
  * **重點**：掌握字典 `{ }` 的 `Key: Value`（鍵值對）儲存概念，並練習用中括號指定 Key 讀取資料。

* **`08_dict_mod.py`**
  * **功能**：修改現有聯絡人的電話資料，並為字典擴充新增電子信箱欄位。
  * **重點**：學習如何透過指定 Key 直接修改舊欄位數值，或是直接指派新 Key 來動態新增欄位。

* **`09_dict_del.py`**
  * **功能**：在個人資料字典中，將暫時離線的狀態欄位從字典中移除。
  * **重點**：掌握 `.pop()` 方法的妙用，除了能將指定 Key 刪除外，還能順便提取出被刪除的數值。

* **`10_dict_loop.py`**
  * **功能**：使用迴圈自動走訪整張學生成績單字典，將所有科目與對應分數一併印出。
  * **重點**：學習運用 `.items()` 方法將字典拆解，在 `for` 迴圈中同時對 Key 與 Value 進行拆包處理。

## 📁 Step 05：函式（Function）
本階段學習如何將常用的程式碼邏輯打包成函式（Function），提高程式碼的重複利用性與模組化能力。

* **`01_hello_func.py`**
  * **功能**：定義一個印出系統開機與歡迎訊息的自訂函式，並多次呼叫執行。
  * **重點**：掌握 `def` 關鍵字定義函式的方法，以及呼叫（Call）函式的基本語法。

* **`02_add_func.py`**
  * **功能**：建立帶有參數的加法函式，傳入不同數值並自動計算列印出結果。
  * **重點**：理解「參數（Arguments）」概念，學習如何將外部資料傳遞給函式內部處理。

* **`03_return_max.py`**
  * **功能**：比對兩數大小並透過 `return` 回傳較大值，供外部變數接收並做後續計算。
  * **重點**：掌握 `return` 關鍵字的回傳機制，理解它與單純 `print()` 的本質差異與用法。

* **`04_default_param.py`**
  * **功能**：建立打招呼函式並設定預設參數，示範傳入自訂名稱與未傳參時的保底結果。
  * **重點**：學習如何設定「預設參數值（Default Parameters）」，以及預設參數必須放在參數列表後方的規則。

* **`05_local_global.py`**
  * **功能**：實作全域變數與區域變數的讀取測試，觀察變數在函式內外的存取限制。
  * **重點**：理解變數的作用域Scope，區分全域變數與區域變數。

## 📁 Step 06：檔案處理與例外捕捉（File I/O & Exception Handling）
本階段學習如何使用 Python 進行檔案讀寫操作（.txt），並結合例外捕捉機制（try-except）與 `with` 語法，建立穩定且具備資料持久化能力（Data Persistence）的程式庫。

* **`01_file_write.py`**
  * **功能**：建立文字檔並寫入內容，若檔案不存在會自動建立，若存在則會覆蓋。
  * **重點**：掌握 `open()` 搭配 `"w"` (Write) 寫入模式，並使用 `encoding="utf-8"` 防止文字亂碼。

* **`02_file_read.py`**
  * **功能**：讀取已存在的文字檔內容，並將文字完整顯示於終端機畫面中。
  * **重點**：理解 `"r"` (Read) 讀取模式與 `.read()` 方法的使用，以及相對路徑（如 `Step_06/note.txt`）的設定方法。

* **`03_file_append.py`**
  * **功能**：在不破壞舊有檔案內容的前提下，於文字檔最末端附加寫入新資料。
  * **重點**：掌握 `"a"` (Append) 附加模式，理解它與覆蓋寫入模式（`"w"`）的差異。

* **`04_try_except.py`**
  * **功能**：模擬讀取不存在的檔案時，利用例外捕捉攔截錯誤，防止程式崩潰中斷。
  * **重點**：學習 `try-except` 防護機制與 `FileNotFoundError` 錯誤型態，提升程式的容錯性與穩定度。

* **`05_with_statement.py`**
  * **功能**：使用 Python 官方推薦的 `with open(...)` 語法自動管理檔案開啟與關閉流程。
  * **重點**：掌握 Context Manager（內文管理器）概念，省去手動呼叫 `file.close()` 的步驟，確保系統資源安全釋放。

本階段學習如何擴充 Python 功能，包含使用內建模組、模組化開發（自製跨檔案模組）、透過 `pip` 工具安裝並使用第三方套件，以及解析JSON資料與管理專案套件依賴。

* **`01_builtin_modules.py`**
  * **功能**：運用 Python 內建的核心工具箱，進行數學運算與時間處理。
  * **重點**：掌握 `import` 語法，靈活使用 `math` 模組計算圓周率/平方根，以及 `datetime` 模組進行時間格式化輸出。

* **`02_custom_module.py`** & **`my_tools.py`**
  * **功能**：將自訂函式獨立封裝於 `my_tools.py`，並在主程式中載入呼叫。
  * **重點**：理解 Python 模組化（Modular programming）架構，實現跨檔案程式碼重用與清晰的專案分工。

* **`03_requests_demo.py`**
  * **功能**：透過套件向網路公開 API 發送 HTTP GET 請求並接收回應
  * **重點**：學習使用 `pip install` 指令安裝第三方套件，掌握 `requests` 模組與 HTTP 狀態碼（如 200 OK）觀念

* **`04_json_parse.py`**
  * **功能**：解析網路傳回或字串格式的 JSON 資料，轉為 Python 字典結構

* **`05_requirements.py`**
  * **功能**：示範與管理專案所需的第三方套件清單
  * **重點**：掌握 `pip freeze > requirements.txt` 導出套件清單與 `pip install -r requirements.txt` 安裝
